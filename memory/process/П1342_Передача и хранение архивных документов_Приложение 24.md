**ЧАСТЬ 1.2**

# Процесс П1342: Передача и хранение архивных документов

---

Приложение 24
Требования к верификации оригиналов КОД по непокрытым аккредитивам для сегментов (КСБ/CIB/ММБ)

Основные требования к параметрам оформления КОД сегмента КСБ/CIB/ММБ по непокрытым аккредитивам, обязательным при верификации:

Каждый лист должен быть подписан. В т.ч. наличие подписей не менее двух свидетелей в договорах поручительства физических лиц, в случае если договор поручительства не удостоверен нотариально:

со стороны Клиента/Поручителя/Залогодателя - подписавшим договор лицом, либо лицом, уполномоченным Доверенностью/ Приказом/ Распоряжением руководителя Клиента/ Поручителя/ Залогодателя;

со стороны Банка - лицом, подписавшим договор, либо лицом, уполномоченным Доверенностью/ Приказом/ Распоряжением руководителя Банка.

В текстах договоров все денежные суммы (при наличии) должны быть обозначены хотя бы один раз прописью.

Фамилии, имена, отчества (при наличии) лиц, подписавших оригиналы документов, адреса, любые наименования в текстах договоров должны быть написаны без сокращений.

Договор должен быть подписан уполномоченными лицами и скреплен печатями сторон по договору.

По сегментам CIB и КСБ - все договоры поручительства и дополнительные соглашения к ним, заключаемые с физическими лицами, должны быть нотариально удостоверены  (вступают в силу после указанного нотариального удостоверения) либо подписаны с соблюдением следующих условий:

рукописной расшифровки поручителем его фамилии, имени, отчества (при наличии);

наличия подписей не менее 2-х свидетелей (сотрудников Банка) подписания договора поручительства с указанием фамилии, имени, отчества (при наличии) и паспортных данных.Устранение ошибок верификации для оригиналов КОД по непокрытым аккредитивам (КСБ/CIB/ММБ)

1. Устранением замечаний, выявленных при верификации, может считаться:

заключение дополнительного соглашения к договору;

предоставление служебной записки СПБ о невозможности внесения изменений в документ в целях устранения несоответствий/ ошибок, выявленных в процессе верификации, с указанием причин(ы) и результатов рассмотрения создавшейся ситуации с заинтересованными подразделениями ЦА/ТБ;

дооформление оригинала документа/договора в соответствии с Приложением 19.1 для КОД по непокрытым аккредитивам (КСБ/CIB/ММБ).

2. При замене скан-копии документа (номер выявленного несоответствия в Классификаторе ошибок 238.5.4., 238.5.5. (получено объяснение СПБ о размещении в ФП ГС скан-копии экземпляра договора контрагента), 238.5.1., 238.5.2. Приложения 19.1) ответственный сотрудник СЦ Архив осуществляет контроль за размещением СПБ в ФП ГС скан-копии, соответствующей оригиналу документа, направленного на хранение.

3. Возврат оригинала КОД по непокрытым аккредитивам с хранения в связи с переоформлением документа может быть произведен по запросу СПБ только после поступления на хранение (установленным порядком) вновь оформленного документа. Первоначальный документ СПБ уничтожает с оформлением акта об уничтожении. СПБ должно обеспечить уничтожение всех подлинных экземпляров первоначального документа.
